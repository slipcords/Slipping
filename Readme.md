## Assets

- `sounds/` — sound effects used by plugins (keyboardSounds, animalese, equissant, moyai, waitForSlot, ...)
- `icons/` — icon assets used by plugins
- `images/` — banners and general image assets
- `badges.json` / `devs.json` / `plugins.json` — plugin metadata and developer information
